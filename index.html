Drift-Triggered Retraining Policies Under Budget and Latency Constraints
An empirical study comparing three model retraining strategies - periodic, error-threshold, and drift-triggered (ADWIN) - for machine learning systems exposed to concept drift in production streams. Experiments span 3,933 runs across synthetic and real-world datasets (network intrusion detection and loan default prediction), examining how retraining policies trade off accuracy, compute cost, and deployment latency. The work addresses a practical systems problem: when and how to retrain a deployed model given limited budget and unavoidable update delays.
Python Machine Learning Streaming ML Concept Drift scikit-learn
